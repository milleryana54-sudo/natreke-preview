NATREKE — загрузка на GitHub Pages

В архиве лежат сами файлы сайта (не нужно загружать ZIP как один файл).

1. Распакуйте архив полностью.
2. Создайте новый PUBLIC-репозиторий github.com/new с именем natreke-preview и включите Add a README file.
3. На странице репозитория выберите Add file > Upload files.
4. Перетащите СОДЕРЖИМОЕ распакованной папки, а не ZIP. В корне репозитория должны оказаться index.html, папки assets/, bali/, kyrgyzstan/, nepal/, reviews/.
5. Подтвердите загрузку (Commit changes).
6. Settings > Pages > Source: Deploy from a branch > Branch: main > /(root) > Save.
7. Адрес: https://ВАШ-ЛОГИН.github.io/natreke-preview/
