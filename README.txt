NATREKE Nepal — вариант А на основе присланного v7 route3 holographic

Замените папку nepal целиком в natreke-preview.
Открыть: nepal/index.html#route
Для отдельного просмотра карты: nepal/landscape/index.html

Изменён только экран карты и его сигнал видимости в основной презентации.
Остальные 23 экрана, данные рельефа и координаты стоянок сохранены.

Большая нижняя панель удалена. Маршрут автоматически проходит все 14 стоянок
туда и обратно, с короткими остановками. В конце движение останавливается.
Кнопки паузы/продолжения и повтора находятся в существующей верхней строке.
Пройденные стоянки обозначены ромбами, будущие — приглушёнными точками.
Текущая точка светится, пройденная часть пунктира ярче будущей.
Название и высота показывают последнюю достигнутую стоянку при движении.
Тонкая линия снизу показывает прогресс полного маршрута.
При уходе с экрана движение замирает, при возврате продолжается;
ручная пауза сохраняется. Прокрутка на телефоне не перехватывается.

Reduced-motion: автоматическое движение отключено. Кнопка стрелки
переключает стоянки без анимации; повтор возвращает в начало.

Проверено в Chrome: 1440×1000 и 390×844, полный проход до Луклы,
повтор, пауза, прокрутка с уходом и возвратом, reduced-motion.
В тестах полного маршрута использовалось ускоренное время.
Реальные скриншоты страницы приложены отдельно.

Данные высот, код, изображения находятся локально; сборка и API-ключи не нужны.
GitHub не обновлялся. Корневая главная страница существующего сайта в архив не входит.
