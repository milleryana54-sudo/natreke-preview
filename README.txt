NATREKE Nepal: v7 + объёмный слайд 3

Замените папку nepal в существующем GitHub Pages репозитории целиком.
Точка входа: nepal/index.html
Прямой переход к маршруту: nepal/index.html#route

Изменён только слайд 3. Остальные 23 экрана сохранены из v7 без изменений.
В папке nepal/landscape находятся локальные данные рельефа, оформление, управление и кадры из v7.
Все эти файлы необходимы. Не загружайте только один index.html.
Сборка, ключ картографического сервиса и подключение внешних библиотек не нужны.

14 этапов: Лукла, Пхакдинг, Намче-Базар, Тенгбоче, Дингбоче, Лобуче, Горакшеп,
Кала-Паттхар, базовый лагерь, Горакшеп, Фериче, Кхумджунг, Пхакдинг, Лукла.
Названия, высоты и порядок взяты из исходной карты v7.

Можно выбирать стоянки в списке или на модели, поворачивать ландшафт,
приближаться, проходить путь автоматически и перематывать его в обе стороны.
Стрелки «Предыдущий экран» и «Следующий экран» возвращают к основной презентации.

Горы построены по реальным данным высот из предоставленного 214.png.
Вертикальный масштаб усилен в 1,8 раза. Цвета и снег являются оформлением модели.
Линия соединяет стоянки схематично и не является туристическим GPS-треком.
Источник рельефа: Mapzen Terrain Tiles, AWS Registry of Open Data.
https://registry.opendata.aws/terrain-tiles/

Ссылки на главную страницу и favicon сохранены относительно корня существующего сайта.
Главная страница, favicon и другие разделы сайта в этот архив не входят.
