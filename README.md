# NATREKE — интерактивная версия v5

Сайт работает без сервера разработки и может быть опубликован на обычном статическом хостинге, в том числе через GitHub Pages.

## Как открыть
1. Распакуйте архив полностью, сохраняя структуру папок.
2. Откройте `index.html` в браузере или разместите папку на тестовом хостинге.
3. Для максимальной совместимости автозапуска видео используйте HTTPS-хостинг: некоторые браузеры ограничивают медиа при открытии с диска.

## Навигация
- `/` — главная с анимированной историей и вращающимся 3D-глобусом (реальная Canvas 3D-проекция, без внешних библиотек).
- `/kyrgyzstan/` — исходная интерактивная презентация Кыргызстана, с полным фильмом.
- `/nepal/` — исходная интерактивная презентация Непала.
- `/bali/` — интерактивная презентация Бали.
- `/reviews/` — история участницы.

## Дизайн
- Цвет фона: #F8F8F5, глубокий графит: #101B1D, терракотовый — точечный акцент #C46B49.
- Все заголовки без засечек и без курсива (Onest / Manrope с fallback Arial).
- Полноэкранный монтаж из оригинальных видео, а не стоковые кадры.
- Прокручиваемая история из трёх фотографий, 3D-сфера с тремя географическими пинами, карточки маршрутов с мягким наклоном при наведении.
- Motion-reduced режим и мобильная адаптация.

## Важно перед запуском продаж
- Сейчас нет формы оплаты, встроенного платёжного шлюза, политики обработки персональных данных и публичной оферты. Никакой платёж через текущие кнопки не взимается.
- Кнопки связи ведут на номер Андрея, указанный в исходных материалах.
- Даты и цена представлены согласно последним комментариям заказчика: Кыргызстан — июнь–июль, 135 000 ₽; Непал — апрель–май (без стоимости); Бали — март 2026, 235 000 ₽. Конкретные даты не выдумывались.
- Иллюстрации из пользовательских фото; перед коммерческой публикацией проверьте согласие людей на использование их изображений и права на медиа.

## Тест
- Главная проверена на ширине 1440px и 390px: горизонтального переполнения и JavaScript-ошибок нет.
